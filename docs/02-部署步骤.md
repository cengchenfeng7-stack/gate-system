# 02-部署步骤

## 前置条件

- GitHub 仓库（本仓库）
- Cloudflare 账号
- Python 3.10+（前端）
- OpenVPN Community（B 端，可选）

## 第 1 步：部署 checker worker

1. Dashboard → Workers & Pages → **Create** → 名字 `checker`（或任意）
2. 编辑代码 → 粘贴 `workers/checker/CheckSocks5_hardened.js` 全文 → 部署
3. 设置 → 变量：
   - KV 命名空间 → 名称 `KV` → 选你的命名空间（可选，checker 不强依赖）
   - 机密 → `TOKEN` = 随机字符串（可选，防白嫖）
4. 域 → 添加自定义域（如 `check.example.com`）
5. 验证：`https://<worker>.workers.dev/check?sstp=vpn:vpn@vpn2070.opengw.net:5555`
   - 预期：`"success": true` + exit 字段

## 第 2 步：部署 vless worker

1. Dashboard → Workers & Pages → **Create** → 名字 `vless`
2. 编辑代码 → 粘贴 `workers/vless/worker.js` 全文 → 部署
3. 设置 → 变量：
   - KV 命名空间 → 名称 `KV` → 选你的命名空间（存 config.json 等）
   - 机密 → `ADMIN` = 你的后台密码
4. 域 → 添加自定义域（如 `vless.example.com`）
5. 登录后台：`https://<域名>/admin` → 用 ADMIN 密码登录
6. 配置 VLESS 节点（UUID + 服务器地址）—— **这一步省不掉，不然订阅是空的**
7. 验证：`https://<域名>/sub?token=<订阅token>&b64` → 应返回节点列表

## 第 3 步：配置 GitHub Secrets

仓库 → Settings → Secrets and variables → Actions → New repository secret：

| Secret | 值 | 说明 |
|---|---|---|
| `WORKER_CHECK_URL` | `https://<checker>.workers.dev/check?sstp=vpn:vpn@` | 检测 Worker 地址（含凭证后缀） |
| `SSTP_USER` / `SSTP_PASS` | `vpn` / `vpn` | 可选，默认 vpn/vpn |

## 第 4 步：配置 GitHub Pages

仓库 → Settings → Pages → Source: **GitHub Actions**
（workflow 会自动发布 web/ 产物）

## 第 5 步：触发首次运行

GitHub → Actions → 选 workflow → **Run workflow**

预期日志：
```
========== VPN GATE ==========
获取原始节点: 96 | SSTP 节点: 83 | 去重后: 80
========== CLOUDFLARE WORKER ==========
提交检测: 80 (并发 16, ...)
最终稳定可用: N | 淘汰/失败: M (Worker 异常 K)
========== RESULT ==========
入选精选节点: N | ⭐客服稳连 X | 🎮游戏 Y | ⬇️下载 Z | 🤖AI W
```

## 第 6 步：验证

- Pages 面板：`https://<你的用户名>.github.io/<仓库>/`
- 四场景数字 > 0
- 节点列表可复制

## 注意事项

- **不要**在 secret 里加 `?token=` 除非 worker 也设了 TOKEN
- checker 不需要绑 KV/ADMIN（无状态）
- vless worker 的 ADMIN 密码要记好，忘了进不去后台
- 首次部署后 DNS 传播可能需要几分钟
