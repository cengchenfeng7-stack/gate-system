# 03-配置说明

## 环境变量（GitHub Actions）

| 变量 | 默认 | 说明 |
|---|---|---|
| `WORKER_CHECK_URL` | （必填） | 检测 Worker 地址，如 `https://<worker>.workers.dev/check?sstp=vpn:vpn@` |
| `SSTP_USER` / `SSTP_PASS` | `vpn` / `vpn` | 生成链接使用的凭证 |
| `MAX_PER_COUNTRY` | 6 | 每国最多保留几个节点 |
| `CHECK_CONCURRENCY` | 16 | 检测并发（>16 容易打爆 Worker 免费版） |
| `CHECK_TIMEOUT` | 45 | 单节点检测超时（秒） |
| `MAX_CHECK_NODES` | 0 | 每轮最多检测多少节点（0=不限） |
| `DOUBLE_CHECK_TOP` | 1 | 是否二次复测前排候选 |
| `SUPPORT_MIN_UPTIME_H` | 12 | ⭐客服：最少在线小时 |
| `SUPPORT_MAX_SESSIONS` | 120 | ⭐客服：最大负载人数 |
| `SUPPORT_MAX_JITTER` | 150 | ⭐客服：抖动上限 ms |
| `SUPPORT_MAX_LATENCY` | 600 | ⭐客服：延迟上限 ms |
| `GAME_MAX_LATENCY` | 400 | 🎮游戏：延迟上限 ms |
| `GAME_MAX_JITTER` | 100 | 🎮游戏：抖动上限 ms |
| `GAME_MAX_SESSIONS` | 250 | 🎮游戏：最大负载人数 |
| `SPEED_MIN_MBPS` | 2 | ⬇️下载：最低账面带宽 |
| `SPEED_MAX_SESSIONS` | 250 | ⬇️下载：最大负载人数 |
| `AI_MIN_UPTIME_H` | 6 | 🤖AI：最少在线小时 |
| `AI_MAX_JITTER` | 200 | 🤖AI：抖动上限 ms |
| `AI_MAX_LATENCY` | 800 | 🤖AI：延迟上限 ms |
| `EDGE_HOSTS` / `HOSTS_ENTRY` | 内置 9 个 | 入口域名列表（逗号分隔） |
| `BAN_FILE` / `PIN_FILE` | `ban.txt` / `pin.txt` | 黑名单/置顶名单文件路径 |
| `EXTRA_ENTRY_TOP` / `EXTRA_ENTRY_COUNT` | 3 / 2 | 每场景前 N 名附加几个备用入口行 |

## Cloudflare Worker 变量

### checker worker

| 变量 | 类型 | 说明 |
|---|---|---|
| `TOKEN` | 机密 | /check 接口访问密码（可选） |
| `BEIAN` | 文本 | 面板底部备案内容（可选） |

### vless worker

| 变量 | 类型 | 说明 |
|---|---|---|
| `ADMIN` | 机密 | 后台登录密码（必填） |
| `UUID` | 文本 | VLESS 节点 UUID（可选，未设则显示 noKV 页） |
| `HOST` | 文本 | 自定义域名（用于生成订阅链接） |
| `KV` | 绑定 | KV 命名空间（存 config.json 等） |

## GitHub Secrets

| Secret | 必填 | 说明 |
|---|---|---|
| `WORKER_CHECK_URL` | ✅ | 检测 Worker 地址（含 `?sstp=vpn:vpn@` 后缀） |
| `SSTP_USER` / `SSTP_PASS` | ⬜ | 默认 vpn/vpn |

## 阈值调优建议

- **CF 免费版额度**：检测并发 16、零重试、复测只测每国前 8 名
- **节点数偏少**：检查 feed 是否被限流（raw_nodes < 50）
- **客服/AI 场景凑不出节点**：放宽 `SUPPORT_MIN_UPTIME_H` 或 `AI_MIN_UPTIME_H`
- **游戏场景延迟高**：检查 `GAME_MAX_LATENCY` 是否太严

## 手动干预：黑名单与置顶

### ban.txt — 永久掐死节点

```
vpn12345.opengw.net          # 掐掉该主机所有端口
vpn12345.opengw.net:1194     # 只掐这一个 host:port
```

### pin.txt — 手动置顶保送

- 排到每个场景文件最顶部（📌 标记）+ 自动附加 2 个备用入口行
- 免场景门槛：只要本轮检测成功，必进全部四条场景通道
- 安全底线：置顶不能把脏IP塞进客服/AI 通道
- 置顶的节点若本轮检测失败会被跳过并在 Actions 日志告警
