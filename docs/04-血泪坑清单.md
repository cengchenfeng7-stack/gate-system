# 04-血泪坑清单

> 这些坑都是实际踩过的，别再踩。

## 1. 检测全失败（81/81）

**症状**：Worker 返回 200 且 worker_error=0、6.3 秒内全部业务失败。

**根因**：GitHub Secret `CHECK_WORKURL` 的 `?sstp=` 后**没带 `vpn:vpn@` 凭证** → 每个节点都以 `SSTP server requires PAP authentication` 快速失败。

**修复**：secret 改成 `https://<worker>.workers.dev/check?sstp=vpn:vpn@`。

**教训**：前端拼接 URL 时，secret 的格式必须和 worker 的参数解析方式匹配。带凭证的 secret + 前端拼 host:port = 完整 URL。

## 2. worker 半死不活（部分路径 522/1101）

**症状**：根路径返回 nginx 页（活着），但 /login 超时、/sub 重置、自定义域 522。

**根因**：
- /login 超时：代码从 `edt-pages.github.io`（GitHub Pages）拉登录页，GitHub 不可达 → fetch 挂起
- 自定义域 522：DNS 未解析或路由未配置

**修复**：
- 自定义域：确认域已正确添加到 worker（不是只存在于 zone）
- /login：改代码内嵌页面，不依赖 GitHub

**教训**：edgetunnel 代码依赖 GitHub Pages 拉页面，GitHub 不可达时后台全废。私人部署建议内嵌。

## 3. 自定义域 1016 Origin DNS error

**症状**：访问自定义域返回 1016。

**根因**：自定义域没真正挂到 worker（只在 zone 里存在，没添加到 worker 的域列表）。

**修复**：worker → 域 → 添加自定义域。

**教训**：CF 的"域"和"自定义域"是两回事。zone 里有 ≠ worker 绑了。

## 4. 本地两个流水线副本不一致

**症状**：`能跑版` 和 `gate` 目录内容哈希不同。

**根因**：开发过程中只更新了一处。

**修复**：统一到 `能跑版`，另一处删除或同步。

**教训**：多副本 = 灾难。只维护一份源码，其他用符号链接或删除。

## 5. PowerShell 中文路径乱码

**症状**：`Get-ChildItem 'F:\稀奇玩意\能跑版'` 找不到路径。

**根因**：磁盘目录名是双重重编码（UTF-8→GBK→GBK），`-like` 匹配失败。

**修复**：
- 直接指定中文路径作为参数（`Get-ChildItem 'F:\稀奇玩意\能跑版'`）可以工作
- 先列目录再匹配中文模式会失败
- 用 glob/read 工具代替 PowerShell

**教训**：规则 6 存在的原因。用动态路径或直接字面量，别用 `-like` 匹配中文。

## 6. Compare-Object 行级 diff 误导

**症状**：diff 出几百行"差异"，实际只是对齐噪声。

**根因**：Compare-Object 在 HTML 块不同的两个文件上会产生大量错位噪声。

**修复**：用函数级 diff（按函数名提取全文比对），或精确指定行号范围。

**教训**：大文件 diff 不要用 Compare-Object 的行级结果做判断依据。

## 7. CF Worker 面板有第三方埋点

**症状**：旧版 checker 面板每次被打开就向 `tongji.090227.xyz` 汇报 worker 域名。

**根因**：cmliu 上游代码内嵌的访问统计脚本。

**修复**：hardened 版已移除。部署 hardened 后检查面板源码无 `tongji` 字样。

**教训**：公开 worker 的面板代码要审计，第三方埋点会泄露私有域名。

## 8. GitHub Actions 日志只打计数，不打 error

**症状**：检测失败时只知道"失败 80"，不知道各死在哪。

**根因**：vpngate.py 的 build_outputs 只持久化 success 节点，error 被丢弃。

**修复**：M6（失败原因聚合）——check_all 后聚合 Top 错误文案落 data.json.diagnostics。

**教训**：规则 2（失败不静默）的体现。错误信息必须落盘/打日志。

## 9. .github 文件夹上传丢点号

**症状**：通过某些方式上传 .github 文件夹，点号丢失。

**修复**：用 GitHub 网页 Create new file 手打路径 `.github/workflows/check.yml`。

**教训**：规则 7 存在的原因。

## 10. Cloudflare Workers 绑定名必须和代码一致

**症状**：代码用 `env.KV`，dashboard 绑定名却是 `muchen` → 代码读到 undefined → 崩溃。

**修复**：dashboard 绑定名改成 `KV`（和代码里写的一致）。

**教训**：Workers 绑定是按名字注入的。代码写 `env.KV`，dashboard 就必须叫 `KV`。
