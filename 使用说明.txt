==================================================
           智能 Agent 群 - Windows 桌面版
   Windows 原生多模型 AI 专家集群与系统自动化实操中枢
==================================================

【系统环境要求】
  • 支持操作系统: Windows 10 / Windows 11 (64位)
  • 内置独立运行环境，无需用户手动安装 Node.js 或编译器，解压即用。

【快速启动与使用】
  1. 解压到任意目录（建议路径不包含中文或空格，例如 D:\AgentSquad 或 E:\222\智能Agent群-Windows11）。
  2. 双击运行 "智能Agent群.exe"。
  3. 程序将静默拉起后台服务（无任何 CMD 黑色控制台弹窗干扰），并在右下角系统托盘常驻运行。
  4. 首次启动会自动在默认浏览器中打开控制台：http://localhost:3000

【系统托盘常驻功能 (右下角图标)】
  • 鼠标双击图标：一键打开或唤起网页控制台。
  • 鼠标右键托盘图标可呼出管理菜单：
      - 打开工作台 (http://localhost:3000)
      - 模型与系统设置 (/settings)
      - 管理控制台 (/admin)
      - 重启后台服务 (一键热重启，无需任务管理器强杀)
      - 查看运行日志 (实时查看 server.log / server.err.log)
      - 编辑配置文件 (.env)
      - 开机自启 (勾选后静默启动到托盘，不弹浏览器)
      - 全局快捷键设置 (点击输入框后直接按下新的组合键)
      - 运行状态与关于 (查看当前进程 PID、端口、快捷键与健康度)
      - 退出程序 (安全平稳退出，Windows 内核级自动清理子进程，杜绝僵尸进程残留)
  • 系统通知：后台任务完成、编码任务完成/失败、后台服务断开/恢复时，会在右下角弹出通知。
  • 未读角标：有未读通知时托盘图标右下角显示红色数字，全部已读后自动消失。

【全局快捷键 (v2.8)】
  • Ctrl+Alt+Space：唤起工作台；工作台已在前台时最小化。
  • Ctrl+Alt+X：全局划词。在任意应用中选中文字后按此快捷键，
    工作台顶部会浮出划词工具条，可翻译 / 解释 / 总结 / 存笔记 / 复制。
  • 捕获划词时会临时使用剪贴板，完成后自动恢复原剪贴板内容。
  • 快捷键冲突时可在托盘菜单「全局快捷键设置…」中重新录制。

【全新前端可视化三大运行模式】
  无需再手动在输入框打字输入前缀，聊天输入栏顶部自带模式胶囊切换：
  1. ⚡【单 AI 执行】（默认推荐）：
     跳过多角色轮询与寒暄，由全能开发/排查 Agent 1v1 直接响应，全力调用底层工具执行任务。
  2. 🔄【自动工作流】：
     输入复杂系统任务，多 AI 将自动按照【Stage 1 架构规划 -> Stage 2 核心编码 -> Stage 3 测试验证】接力流水线交付。
  3. 👥【专家群聊】：
     保留经典多专家研讨机制，各岗位专家针对问题碰撞讨论，汇总达成共识并联合触发工具。

【模型提供商接入与切换】
  打开网页端 http://localhost:3000/settings 即可在可视化面板中自由选择并保存：
  • 方式一：通用 OpenAI 兼容协议（推荐）
     支持 DeepSeek、GPT-4o、Kimi、通义千问、硅基流动等各大云端大模型，填入 Base URL、API Key 与 Model ID 即可。
  • 方式二：Claude 官方规范
     填入 Anthropic API Key，无缝调用 Claude 3.5 Sonnet 等官方模型。
  • 方式三：本地 Ollama 私有化部署
     启动本地 Ollama 服务后，自动读取 /api/tags 模型列表，支持离线私密运行。
  （注：设置保存后立即热更新并回写 .env，无需重启生效。）

【系统级 14 项实操工具箱】
  1. 文件操作: read_file (读取文件)、write_file (写入文件)、edit_file (精准替换)、list_directory (浏览目录)
  2. 终端执行: execute_command (PowerShell/CMD 脚本执行，自带 30s 熔断防卡死保护)
  3. 桌面 GUI 自动化: gui_windows (窗口管理)、gui_tree (UI 控件树)、gui_find (精准查找)、gui_inspect (元素检查)、gui_click (真实点击)、gui_type (物理输入)
  4. 多模态视觉感知: screen_capture (即时像素截屏，网页直观渲染图片)、screen_monitor (动态连续连拍与变化监控)
  5. 系统专用排查: system_diagnostics (Windows 事件日志警告错误、监听端口占用、CPU/内存进程排查、服务状态)

【快捷访问入口】
  • 智能 Agent 聊天工作台: http://localhost:3000
  • 模型与系统设置面板:    http://localhost:3000/settings
  • 管理与对话审计控制台:  http://localhost:3000/admin
  • 接口工具健康自检:      http://localhost:3000/api/tools/test
